# Sniffer

Простой сетевой сниффер, написанный на Python. Утилита позволяет захватывать сетевые пакеты в реальном времени, анализировать заголовки (Ethernet, IPv4, TCP, UDP) и сохранять трафик в файлы формата PCAP.

## Возможности

*   **CLI-интерфейс**: Удобное управление через командную строку.
*   **Реальное время**: Отображение захваченных пакетов и их детальной информации (MAC-адреса, IP, порты, флаги и т.д.) по мере поступления.
*   **Фильтрация**: Поддержка BPF-фильтров (Berkeley Packet Filter) для захвата только интересующего трафика (например, только TCP порт 80).
*   **Запись в файл**: Возможность сохранения захваченного трафика в валидный `.pcap` файл, который затем можно открыть в Wireshark.
*   **Парсинг протоколов**: Реализован ручной разбор заголовков Ethernet, IPv4, TCP и UDP.

## Требования

*   Python 3.x
*   Библиотека `pcapy` (биндинг к libpcap)

### Установка зависимостей

Для работы сниффера необходимо установить библиотеку `pcapy`. На macOS/Linux также может потребоваться установка системных библиотек `libpcap`.

```bash
pip install pcapy-ng
```
*(Примечание: `pcapy-ng` — это актуальный форк оригинального `pcapy`)*

## Использование

Для запуска сниффера требуются права суперпользователя (root/sudo), так как необходим прямой доступ к сетевым интерфейсам.

### Синтаксис

```bash
sudo python3 main.py [опции] [BPF фильтр]
```

### Опции

*   `-i`, `--interface`
    Указать один или несколько сетевых интерфейсов для прослушивания (например, `-i eth0 lo0`). Если не указан, будет выбран первый доступный интерфейс.
    
*   `-o`, `--output`
    Путь к файлу для сохранения захваченных пакетов (формат .pcap). 
    *При прослушивании нескольких интерфейсов имя файла будет автоматически дополнено именем интерфейса (например, `capture_eth0.pcap`, `capture_lo0.pcap`).*
    
*   `-f`, `--filter`
    Строка BPF-фильтра (альтернатива позиционному аргументу).
    
*   `-l`, `--list-interfaces`
    Вывести список доступных сетевых интерфейсов и выйти.

### Примеры запуска

1.  **Посмотреть список всех интерфейсов:**
    ```bash
    sudo python3 main.py -l
    ```

2.  **Запустить сниффер на интерфейсе по умолчанию:**
    ```bash
    sudo python3 main.py
    ```

3.  **Слушать несколько интерфейсов одновременно:**
    ```bash
    sudo python3 main.py -i en0 lo0
    ```

4.  **Использовать BPF-фильтр (стиль tcpdump) — только ICMP:**
    ```bash
    sudo python3 main.py icmp
    ```

5.  **Комбинация: HTTP трафик на двух интерфейсах с записью в файл:**
    ```bash
    sudo python3 main.py -i en0 lo0 -o plain_traffic.pcap tcp port 80
    ```
    *(Создаст файлы `plain_traffic_en0.pcap` и `plain_traffic_lo0.pcap`)*

## Обработка пакетов

Код вручную разбирает байтовую структуру пакетов, извлекая полезную информацию:
*   **Ethernet**: MAC-адреса отправителя и получателя, тип протокола.
*   **IPv4**: IP-адреса, TTL, протокол верхнего уровня.
*   **TCP**: Порты, Sequence number, Acknowledge number, флаги.
*   **UDP**: Порты, длина пакета.
